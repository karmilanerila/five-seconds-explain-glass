The one sentence a house cat would say five seconds after sweeping a glass off the table — in the cat's own voice. No apology, no confession: the glass had been empty since breakfast and was squatting in the cat's sunbeam, so the cat evicted it.

`main.py` writes that single sentence (128 characters) to `/output/entry.txt`.
